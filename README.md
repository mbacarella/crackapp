# CrackApp 💎

The most overstimulating, dopamine-hijacking app ever made.

CrackApp is a joke PWA designed to be the ultimate comedy prop — pull it out next to someone's minimalist e-ink phone and watch their reaction. It's every dark pattern and attention-exploiting trick crammed into one screen: a gem-tapping clicker with combo multipliers, a slot machine, fake notification toasts, countdown timers, progress bars, a scrolling feed, reward popups, floating emoji particles, and a background music loop that won't quit.

## Try it

**[Play CrackApp](https://mbacarella.github.io/crackapp)** on your phone, then tap **Add to Home Screen** to install it as a fullscreen app for maximum effect.

- **iOS Safari:** tap the Share button, then "Add to Home Screen"
- **Android Chrome:** tap the three-dot menu, then "Add to Home Screen" (or accept the install prompt)

## Tech

Single-page React 18 app with no build step. Babel standalone compiles JSX at runtime, everything runs from five flat files, and all sound is synthesized via the Web Audio API. It installs as a fullscreen PWA on both iOS and Android.
